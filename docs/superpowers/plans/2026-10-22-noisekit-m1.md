# NoiseKit M1 实现计划

依据：[2026-10-22-noisekit-design.md](../specs/2026-10-22-noisekit-design.md)

每个任务都以「可运行 + 有验收命令」为完成标准，不写完就往下走。

## T1 仓库骨架

- `pyproject.toml`：setuptools 后端，`requires-python >= 3.11`，依赖 numpy/scipy，可选组 `audio`(sounddevice)、`gui`(PySide6)、`dev`(pytest/pytest-qt/ruff)；入口脚本 `noisekit = audio_core.cli:main`
- `.github/workflows/ci.yml`：Windows/macOS/Linux 三平台，`ruff check` + `pytest -q`
- 各包 `__init__.py`

**验收**：`pip install -e ".[dev,audio]"` 成功，`noisekit --help` 可执行。

## T2 capture 层

| 文件 | 内容 |
| --- | --- |
| `capture/ring.py` | `RingBuffer`：定长 numpy 缓冲，`write/read/available/overflows`，线程安全（单写单读 + 锁保护计数） |
| `capture/source.py` | `AudioSource` 协议：`sample_rate`、`channels`、`blocks() -> Iterator[ndarray]`、`close()` |
| `capture/synthetic.py` | `SyntheticSource`：正弦/白噪/阶跃，供测试与 `--source synthetic` |
| `capture/wav_source.py` | `WavFileSource`：按真实节奏或全速回放 WAV |
| `capture/devices.py` | `list_devices() -> list[DeviceInfo]`，无 sounddevice 时返回空并给出提示 |
| `capture/stream.py` | `SoundDeviceSource`：PortAudio 回调只写环形缓冲；采样率 48k→44.1k→设备默认 降级协商 |

**验收**：`pytest tests/test_capture.py`；`noisekit --source synthetic --duration 3` 有输出。

## T3 dsp 层

| 文件 | 内容 |
| --- | --- |
| `dsp/framing.py` | 块长计算（10 ms，≥256）、去直流、`mean_square` |
| `dsp/weighting.py` | A/C 计权：模拟原型零极点 → `bilinear_zpk` → `zpk2sos`，1 kHz 归一化到 0 dB；`sosfilt` 带状态流式处理；另提供解析 `a_weight_db(f)/c_weight_db(f)` 供绘图与测试对表 |
| `dsp/time_weight.py` | `TimeWeighter`：Fast 125 ms / Slow 1000 ms / Impulse 上升 35 ms、下降 1500 ms，一阶指数 |
| `dsp/level.py` | `ms_to_dbfs`、`dbfs_to_spl(offset)`、`calibration_offset(ref_spl, measured_dbfs)`，全零保护 |
| `dsp/spectrum.py` | 2048 点 Hann 窗单边谱 → dB，复用于 UI 与报告 |

**验收**：`pytest tests/test_dsp.py`——1 kHz 正弦经 A 计权增益 0±0.1 dB；100 Hz ≈ −19.1±0.5 dB；20 Hz ≈ −50.4±1 dB；白噪 10 s Leq 与解析值误差 < 0.5 dB；Fast 阶跃 63% 时间 ≈ 125 ms。

## T4 metrics 与 analyzers

- `metrics/meter.py`：`FrameMetrics` 数据类（ts、dbfs、db_a、db_c、spl 系列、leq_1s、leq_10s、lafmax、lcpeak）；`SoundLevelMeter.process(block, ts)` 维护计权滤波状态、时间计权、Leq 环形累加器
- `analyzers/base.py`：`Analyzer` 协议 + 注册表 `register/get`
- `analyzers/noise.py`：包装 meter，产出 UI 所需字段
- `analyzers/{music,voice,device}.py`：`NotImplementedError` + docstring 指明计划版本

**验收**：`pytest tests/test_meter.py`——时间戳单调、Leq 收敛、无 NaN（含全零输入）。

## T5 CLI

`audio_core/cli.py`：`--source {device,synthetic,wav}`、`--device`、`--duration`、`--calibrate REF`、`--doctor`（打印后端/设备/版本）、`--list-devices`。终端逐行刷新 dB / dB(A) / Leq(1s) / Leq(10s)。

**验收**：`noisekit --source synthetic --duration 3 --freq 1000` 输出稳定在约 −3 dBFS。

## T6 M1.0 收尾

README 补「当前状态」、CHANGELOG 起 `0.1.0` 条目、CI 绿、提交。

## T7 M1.1 桌面界面

`apps/desktop/`：`main.py` 装配、`worker.py`（QThread，信号限速 30 fps，丢弃积压帧）、`widgets/`（level_meter、time_series 环形数组曲线、spectrum 对数轴、event_list）、`windows/main_window.py`。设备下拉 + 开始/停止 + 状态栏（掉帧计数、水位）。

**验收**：真实麦克风下界面流畅；`pytest-qt` 冒烟通过；连续 10 分钟内存无增长。

## T8 M1.2 告警留证与存储

`events/detector.py`（阈值 + 持续 + 冷却 状态机，纯函数）、`events/recorder.py`（前置环形缓冲 + 后置，写 WAV）、`storage/`（DDL、批量写线程、查询）、`report/`（CSV、内嵌 SVG 的 HTML）。崩溃恢复：启动时把 `ended_at IS NULL` 的会话标记为未正常结束。

**验收**：合成超标信号 → 事件落库 + WAV 可播放 + HTML 报告可打开且含曲线。

## T9 M1.3 校准、打包与文档

校准向导、`--doctor` 排障输出、PyInstaller 打包脚本（显式带 portaudio 动态库）、README 截图、1 小时长跑内存记录。

**验收**：`dist/NoiseKit.exe` 双击可采；长跑内存波动 < 50 MB。

## 风险登记（实现中发现即更新设计）

- A/C 计权的实现方式：设计 §4.3 原定「频域加权」，实际 480 样本块频率分辨率 100 Hz，无法表达 100 Hz 以下的 A 计权衰减，会直接违反自己的验收条件。T3 改为「模拟原型 + 双线性变换的流式 IIR」，并回改设计文档。
